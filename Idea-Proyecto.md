# Idea del Proyecto

## Nombre del proyecto

**Sistema Móvil de Gestión de Inventarios**

## Descripción

El proyecto consiste en desarrollar una aplicación móvil para
dispositivos Android que permita gestionar y controlar el inventario de
un negocio de manera sencilla y organizada.

La aplicación permitirá registrar productos, consultar existencias,
administrar categorías y controlar los movimientos de entrada y salida
de productos. Se busca facilitar el seguimiento del inventario y
disponer de información actualizada para apoyar la administración del
negocio.

## Problema

El manejo manual de inventarios puede generar dificultades para mantener
actualizada la información de los productos, controlar las existencias y
conocer los movimientos realizados. Esto puede ocasionar errores en los
registros, pérdida de información y dificultad para identificar
productos con pocas unidades disponibles.

## Solución propuesta

Se propone desarrollar una aplicación móvil que centralice la
información del inventario y permita realizar las principales
operaciones desde un dispositivo Android.

## Objetivo general

Desarrollar una aplicación móvil en Kotlin que facilite la gestión,
consulta y control de productos y movimientos de inventario.

## Objetivos específicos

-   Permitir el registro y administración de productos.
-   Organizar los productos mediante categorías.
-   Consultar las existencias disponibles.
-   Registrar entradas y salidas de inventario.
-   Mantener un historial de los movimientos realizados.
-   Identificar productos con niveles bajos de stock.
-   Diseñar una interfaz sencilla e intuitiva para el usuario.

## Tecnologías propuestas

-   Kotlin
-   Android Studio
-   Jetpack Compose
-   Room / SQLite

## Usuarios objetivo

La aplicación estará orientada principalmente a pequeños negocios y
personas encargadas de administrar y controlar inventarios de productos.
