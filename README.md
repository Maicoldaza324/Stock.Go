# Sistema de Gestión de Inventarios

Aplicación móvil para la gestión y control de inventarios, desarrollada en Kotlin para dispositivos Android.

## Descripción

El proyecto consiste en desarrollar una aplicación móvil que permita facilitar la administración de productos y el control de inventario de un negocio.

La aplicación busca centralizar la información de los productos y sus existencias, permitiendo consultar y gestionar los movimientos de inventario de manera sencilla.

## Objetivo

Desarrollar una aplicación móvil que facilite el registro, consulta y control de productos y movimientos de inventario.

## Funcionalidades principales

- Inicio de sesión de usuarios.
- Registro y gestión de productos.
- Gestión de categorías.
- Consulta de productos y existencias.
- Registro de entradas de inventario.
- Registro de salidas de inventario.
- Consulta del historial de movimientos.
- Identificación de productos con stock bajo.

## Tecnologías

- Kotlin
- Android Studio
- Jetpack Compose
- Room / SQLite

## Plataforma

Android
