# Definición del Alcance

## Alcance del proyecto

El proyecto contempla el desarrollo de una aplicación móvil para Android
orientada a la gestión básica de inventarios.

La aplicación permitirá administrar información relacionada con
productos, categorías y movimientos de inventario, ofreciendo una forma
sencilla de consultar y actualizar las existencias.

## Funcionalidades incluidas

### Gestión de usuarios

-   Inicio de sesión.
-   Acceso a las funcionalidades principales.

### Gestión de productos

-   Registrar productos.
-   Consultar productos.
-   Editar información.
-   Eliminar productos.
-   Consultar cantidad disponible.

### Gestión de categorías

-   Registrar categorías.
-   Asociar productos a categorías.
-   Consultar productos por categoría.

### Gestión de movimientos

-   Registrar entradas.
-   Registrar salidas.
-   Actualizar existencias.
-   Consultar historial de movimientos.

### Control de stock

-   Consultar inventario actual.
-   Identificar productos con stock bajo.
-   Buscar productos.

## Fuera del alcance

La versión inicial no contempla: - Facturación electrónica. -
Procesamiento de pagos. - Integración con bancos. - Gestión contable
completa. - Integración con sistemas externos. - Comercio electrónico. -
Inteligencia artificial. - Gestión avanzada de proveedores, salvo que
sea requerida posteriormente.

## Límites del proyecto

La aplicación estará enfocada en las operaciones básicas de control de
inventario y será desarrollada inicialmente para dispositivos Android.

## Resultado esperado

Al finalizar se espera contar con una aplicación móvil funcional para
gestionar productos y controlar existencias mediante entradas y salidas
de inventario, acompañada de la documentación y evidencias
correspondientes.
